# Alternative UI/UX Redesign Playground

Purpose: compare up to six independent full-homepage redesigns created by different AI models/windows.

Rules:
- `/` remains the production baseline.
- Each redesign option must remain isolated.
- Never overwrite another option just to create a revision.
- Preserve production content/copy unless the brief explicitly allows changes.
- Reuse assets from `/public` when appropriate.
- A redesign may change layout, typography, motion, interaction, hierarchy, spacing, and visual system.
- Every candidate must consider desktop + mobile.
- Final candidates should pass `npm run build` in the user's local repository before commit/push.
